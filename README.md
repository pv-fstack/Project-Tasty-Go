# ⚡ TastyGo Standalone Web Application (Pure Frontend)

> 100% Pure Frontend Web Project (HTML, CSS, Vanilla JavaScript). **No Python, No Django, No Database setup required!**

---

## 🌟 Key Features

1. **Zero Setup Required**:
   - Double-click `index.html` or open in any browser (Chrome, Edge, Firefox, Safari, Brave).

2. **Pixel-Perfect UI & Typography**:
   - Built using Google Fonts **`Space Grotesk`** & **`Plus Jakarta Sans`**.
   - Ultra-modern dark glassmorphism cards, glowing status badges, and interactive quantity selectors (`[ ➖ ]` `[ 1 ]` `[ ➕ ]`).

3. **Multi-Tab Real-Time Sync (Browser BroadcastChannel API)**:
   - Open **Tab 1** (`track.html?token=TK-104`) and **Tab 2** (`kitchen.html`).
   - When you click **"Mark Ready"** in the Kitchen tab, the Student tab updates **instantly in real time**, plays a 3-tone bell chime sound, and vibrates your phone!

4. **Default Pre-Loaded Orders**:
   - 🟡 **TK-104** → **Dhoni** *(Incoming Orders)*
   - 🟧 **TK-103** → **Hardik Pandya** *(In Kitchen)*
   - 🟢 **TK-102** → **John** *(Ready for Pickup)*

---

## 🚀 How to Run

### Method 1: Double-Click `index.html`
Simply double-click `index.html` in your file manager to open it in your browser!

### Method 2: Open in VS Code
1. Open **VS Code**.
2. Click **File → Open Folder...** and select `tastygo_frontend`.
3. Right-click `index.html` and click **Open with Live Server** (or open `index.html` in your browser).
